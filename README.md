# Interview Management Application

## Description
An easy-to-use web app to help schedule and manage job interviews. Users can log in, create, view, edit, and delete interview schedules with a simple and responsive interface.

## Features
- Login authentication (username: admin, password: 1234)
- Add new interview schedules with candidate details, role, date, time, and interviewer
- View all scheduled interviews in a table
- Edit or delete interviews
- Search interviews by candidate name
- Filter interviews by date
- Responsive design for desktop and mobile
- Navigation between Home, Schedule, and View pages

##  Technologies Used
- HTML5: semantic page structure and forms
- CSS3: modern styles, card UI, table layout, mobile responsiveness
- JavaScript: dynamic interaction, local storage, CRUD operations (Create, Read, Update, Delete), navigation, filtering, authentication

##  Future Improvements
- Backend/database integration for persistent storage
- User authentication with different roles (admin/user)
- Email notifications for interview scheduling
- Calendar integration
- Improved UI/UX animations and validations

##  How to Run
1. Download all the files: `index.html`, `style.css`, `script.js`
2. Keep all files in the same folder
3. Open `index.html` in your browser
4. Log in with username: `admin`, password: `1234` to access functionality.
